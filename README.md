# Amazon Clone by Shaik Muzammil

A modern Amazon-inspired frontend clone built using HTML and CSS.

## Features

* Modern UI Design
* Responsive Layout
* Hero Section
* Product Cards
* Hover Animations
* Sticky Navbar
* Glassmorphism Effects
* Attractive Footer
* Mobile Responsive Design

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries
* Font Awesome
* Google Fonts
